# Initial Flow Chart

This flow chart captures the key user journey and AI interaction for the budgeting app.

## Main flow

1. User launches app
2. Home dashboard shows:
   - current budget status
   - total spending
   - goal progress
   - AI insight summary
3. User chooses an action:
   - Add expense
   - View report
   - Set goal
   - Ask AI question
4. If user adds expense:
   - Enter amount, category, date, note
   - Save expense
   - Update dashboard and insight data
5. If user views report:
   - Show categorized spending trends
   - Highlight overspending categories
   - Display savings progress
6. If user sets goal:
   - Enter target amount and deadline
   - Show goal progress widget
   - Add goal to dashboard
7. If user asks AI question:
   - Collect query
   - Analyze user data
   - Generate conversational response
   - Display answer with follow-up suggestions

## AI interaction flow

1. User request or periodic review triggers AI analysis.
2. AI collects recent expense and budget data.
3. AI identifies patterns and opportunities.
4. AI prepares a response with:
   - saving tip
   - spending insight
   - action recommendation
5. App displays response in the chat or insight panel.

## Notes

- The AI agent is built around user data, not generic financial advice.
- The app should surface insights quickly and keep the user focused on one clear action at a time.
- Users should always be able to return to the dashboard or add a new expense.
